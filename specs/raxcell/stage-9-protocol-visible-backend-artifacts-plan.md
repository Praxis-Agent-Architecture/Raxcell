# Raxcell Stage 9 Protocol Visible Backend Artifacts Plan

Status: Confirmed; expose backend artifacts through prepare.

## Goal

Make backend lowering artifacts visible to upper runtimes through the `prepareRun` protocol surface.

This lets harnesses audit the backend-specific execution plan before calling `run`, without letting Raxcell make approval, human-gate, or strategy decisions.

## User Decision Captured

- Native/backend lowering artifacts should be protocol visible.
- Prefer exposing the artifact shape now so later macOS/Windows runner attachment can fill it without changing the top-level prepare contract.

## Proposed Surface

Add `backendArtifacts` to `PrepareRunResponse`.

```json
{
  "backendArtifacts": [
    {
      "backend": "linux-bubblewrap",
      "format": "linux-bubblewrap-argv",
      "arguments": ["--die-with-parent"],
      "data": {
        "executable": "/usr/bin/bwrap"
      },
      "warnings": []
    }
  ]
}
```

## Semantics

- `backendArtifacts` is generated by `prepareRun`.
- It is backend-specific and audit-oriented.
- It must not contain approval decisions or upper strategy output.
- Linux returns a bubblewrap argv artifact immediately.
- macOS/Windows keep fail-closed host behavior; their artifact builders remain source-level until native prepare/run is attached on matching hosts.

## Completion Criteria

- `PrepareRunResponse` includes `backendArtifacts`.
- Linux successful prepare returns a `linux-bubblewrap-argv` artifact.
- SDK exposes `BackendLoweringArtifact`.
- Existing policy-decision prepare responses include an empty artifact list.
- Tests and smoke cover artifact serialization and Linux prepare output.

## Implementation Evidence

Implemented:

- Added protocol type `BackendLoweringArtifact`.
- Added `PrepareRunResponse.backendArtifacts`.
- Linux `prepareRun` now returns a `linux-bubblewrap-argv` artifact containing:
  - selected backend;
  - artifact format;
  - full bubblewrap arguments;
  - `data.executable` with the resolved bwrap path;
  - artifact warnings.
- Policy-decision and fail-closed prepare paths return an empty artifact list.
- TypeScript SDK exposes `BackendLoweringArtifact` and `PrepareRunResponse.backendArtifacts`.

Verified:

- `cargo fmt --manifest-path raxcell/Cargo.toml --all`
- `cargo test --manifest-path raxcell/Cargo.toml`
  - worker: 7 passed
  - core: 30 passed
  - protocol: 9 passed
- `pnpm install && pnpm build:sdk && pnpm test:sdk`
  - TypeScript build passed
  - SDK tests: 6 passed
- `cargo run --manifest-path raxcell/Cargo.toml -p raxcell-cli -- prepare-run --stdin < raxcell/fixtures/prepare-run.linux-bubblewrap.json`

  - included `backendArtifacts[0].format: linux-bubblewrap-argv`
  - included `data.executable: /usr/bin/bwrap`
  - included full bubblewrap argv without executing the command
